# WorkAt

A web-based job portal system for connecting companies with job seekers through online job posting, searching, and application management.

## Technology Stack

### Backend

* ASP.NET Core MVC
* Entity Framework Core (EF Core)

### Database

* Entity Framework Core

## Modules

* Company Registration
* Job Posting
* Job Seeker Registration
* Job Search
* Job Application
* Application Status
* Resume Information

## Database Tables

* Companies
* JobSeekers
* Jobs
* Applications
* Skills
* Resumes

## Features

* Company CRUD
* Job Posting
* Job Search
* Job Application
* Application Status
* Search and Filter
* Login and Role-based Access
